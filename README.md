# 鋼管 内外面積計算 v4.0

## 主な修正

- 20A～1000Aの外径を登録
- 500A以上を含むレジューサーを円すい台として計算
- 古いBASICのU・Vレジューサー定数を廃止
- 直管、エルボー、枝付き直管を寸法から幾何計算
- 10キロ、20キロ、上水F12のフランジ面積を寸法表から計算
- 枝管を複数入力可能
- 計算ボタンを押しても枝管径が初期値へ戻らない
- 画面に v4.0 を表示

## GitHub Pagesで確認

まず `steel_pipe_v4_0.html` をアップロードし、次の形で開くと古いキャッシュを避けられます。
